# Architecture

LMS+는 원본 Smart-LMS를 데이터와 동작의 기준으로 사용하는 비공식 Enhancement Layer다. 목표는 학생이 필요한 정보를 찾아다니는 시간을 줄이는 것이다.

- `src/content/`: 홈 경로·최상위 문서 확인, 독립 React root, 원본 복귀 시 해제. React가 마운트된 후에만 원본 홈을 숨긴다.
- `src/adapter/`: LMS DOM 파싱·기존 동작 호출·읽기 전용 학사일정 조회·허용 링크 검증. UI에서 LMS selector를 직접 사용하지 않는다.
- `src/models/`: 실제 데이터와 미연결/로딩/오류/빈 목록 상태 계약.
- `src/components/`, `src/styles/`: 홈 표현과 상호작용. 985px 기준 폭, hero와 본문 통합 카드, 카드 간격 유지.

## 보안 경계

계정·세션 쿠키를 별도 수집·저장하지 않는다. 서버 HTML은 분리된 inert template에서 텍스트만 읽고 문서에 삽입하지 않는다. 데이터 링크는 HTTPS LMS origin 및 화면 경로를 검사한다. 인증·시험·온라인강의 추적은 원본 LMS가 담당한다. content script는 홈에만 주입하며 ISOLATED world를 유지한다. 권한이나 외부 전송이 늘어나는 변경은 기능 작업과 함께 검토한다.

DOM 구조가 달라지면 성공이나 빈 목록으로 단정하지 않고 원본 접근을 보존한다. 사용자별 값·실제 원본 캡처·비밀값은 Git에 포함하지 않는다. 브라우저 내 표시 데이터는 같은 페이지의 다른 코드로부터 완전히 격리된 개인정보 저장소가 아니다.

현재 홈 범위와 미연결 사항은 README, 확인된 selector와 읽기 요청은 `lms-integration.md`에서 관리한다. 공통 오른쪽 패널, 과목 탐색 개선, 다운로드 설정은 별도 작업이다.

상단 교육현황·커뮤니티·소개는 독립 페이지 탐색이며 현재 홈과 구분한다. 후속 브랜치에서 페이지를 구현한 뒤 연결하고 현재는 비활성으로 둔다. 커뮤니티를 홈 공지 대화상자로 대체하지 않는다. 홈 하단 소모임·OCW·질의응답·자료실은 Adapter에 명시한 확인된 원본 화면으로 이동한다.

홈의 월 이동·날짜 선택·학사일정 조회와 요청 취소는 `CalendarCard`가 담당한다. `Home`은 홈 데이터·검색·대화상자 상태와 섹션 배치를 조합한다. `LmsFooter`는 다른 페이지에서도 재사용할 수 있도록 안내 동작을 콜백으로 받는다. 헤더와 본문은 985px 기준을 유지하고, 푸터 배경은 전체 너비, 내부 콘텐츠는 최대 1200px로 확장한다.

TypeScript·TSX·CSS·테스트와 빌드 설정은 Prettier로 포맷한다. `npm run format:check`로 일관성을 확인한다.

`LmsLayout`은 공통 건너뛰기 링크·헤더·main·푸터·대화상자 영역을 한 번 정의한다. 페이지는 `header`/`footer` 동작, 본문 `children`, 선택적 `overlays`와 본문 클래스를 전달한다. 후속 페이지도 이 레이아웃을 사용하며 헤더·푸터 마크업을 복사하지 않는다. 현재 홈이 이 구조를 사용한다. 홈의 바다 hero와 대학 서비스 이미지 카드는 홈 콘텐츠로 유지한다.

`UniversityLinks`는 홈페이지·포털·웨일비의 이미지 링크 세 개를 렌더링한다. 이미지는 확장에 포함하고 클릭할 때만 해당 사이트를 새 창으로 연다. 이미지 로딩을 위한 외부 요청이나 추가 확장 권한은 없다.
